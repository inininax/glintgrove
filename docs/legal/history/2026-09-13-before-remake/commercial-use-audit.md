# Glintgrove 상업 이용·출처 점검

검토일: 2026-09-13 · 대상 아트 리비전: `nocturne-c4cf96b06729`

이번에 추가한 게임 아트 25개는 로컬 Blender 렌더 21개와 내장 OpenAI 이미지 생성 도구의 배경 4개다. 외부 판매처의 모델·텍스처·배경 파일을 가져온 증거는 없으며, 이번 작업에서 별도 에셋 구매나 유료 API 호출을 하지 않았다. 설치된 Blender는 **5.2.1 LTS**로 확인했다. 생성 도구 이용에는 기존 서비스 요금제·이용 한도가 적용될 수 있으므로, 이를 모든 도구와 이용이 영구 무료라는 뜻으로 해석하면 안 된다.

현재 macOS 26.6.2의 브라우저에서 제목·지도·업적 화면을 열어 확인했다. 제목은 Georgia, 업적 제목의 한글은 AppleMyungjo, 업적의 `🌱`는 Apple Color Emoji로 실제 렌더되며 모두 플랫폼 폰트로 보고된다. 관찰한 리소스 64건에는 외부 origin 요청이 없었고, 웹폰트 선언도 없었다. 관찰 상태·파일 해시·조건은 [런타임 관찰 기록](runtime-visual-observation.json)에 보존했다. 이는 한 브라우저의 관찰이며 다른 기기의 폰트 선택까지 인증하지 않는다.

**현재의 시스템 글꼴·Unicode 표시 방식에는 공식 이용 근거가 있다.** Microsoft는 Windows 글꼴 이름을 CSS 우선순위에 지정할 수 있다고 설명하며 시스템 기호·이모지 글꼴도 안내 범위에 포함한다. Apple macOS SLA §2E는 포함 글꼴의 화면 표시·인쇄를 허용한다. 현재 게임은 폰트 파일이나 이모지 그림 세트를 추출·배포하지 않으므로, 이런 표시를 상업 게임에서 한다는 이유만으로 금지라고 판정하지 않는다. 과거 공유 이미지와 개발용 연락판의 미확인 제작 환경은 별도 항목이다. [Microsoft 글꼴 FAQ](https://learn.microsoft.com/en-us/typography/fonts/font-faq), [Apple Tahoe SLA](https://www.apple.com/legal/sla/docs/macOSTahoe.pdf), [글꼴·기호 상세 점검](fonts-and-symbols.md)

확장 점검에서도 **구체적인 원본 복제나 상업 이용 금지 조건 위반을 확정한 시각 요소는 발견하지 못했다.** 이는 비침해가 입증됐다는 뜻이 아니다. 출처 미확인 파일·AI 결과물의 권리 한계·공개 배포 조건은 아래와 같이 남아 있다.

## 공식 이용 조건

### Blender 결과물과 제작 스크립트

Blender 공식 라이선스는 이미지·영상·`.blend` 등 아트 결과물의 상업 이용을 허용한다. Blender로 렌더했다는 이유로 게임의 PNG/WebP나 게임 코드 전체를 GPL로 공개해야 하는 것은 아니다. 다만 기존 타인 에셋을 Blender에서 열거나 가공했다고 해서 그 에셋의 권리가 새로 생기는 것은 아니다. 이번 원본에서는 외부 연결 파일·이미지 텍스처를 발견하지 못했다. [Blender 공식 라이선스](https://www.blender.org/about/license/)

별도로, Blender Foundation은 `bpy` API를 사용하는 Python 스크립트를 **공개 배포할 때 GPL에 부합하는 라이선스**로 공유하도록 안내한다. `tools/art/build_blender.py`와 `tools/art/render_library.py`가 이 API를 사용한다. 현재 게임은 이 스크립트를 브라우저로 불러오지 않지만, 저장소 전체를 그대로 공개하면 스크립트도 배포될 수 있다. 스크립트 자체를 공개할 경우 해당 파일의 라이선스·고지를 정리해야 한다. 이 점검에서는 게임 전체나 제작 도구에 임의의 라이선스를 부여하지 않았다. [Blender 공식 라이선스 — Add-ons](https://www.blender.org/about/license/)

Pillow 12.3.0은 로컬 변환용 도구이며 설치된 패키지의 메타데이터는 `MIT-CMU`를 표시한다. Blender·Python·Pillow와 함께 제공되는 라이브러리를 직접 재배포하는 경우에는 해당 배포물에 포함된 라이선스·고지도 보존해야 한다. 현재 확인한 브라우저 런타임에는 해당 실행 파일이나 Python 패키지가 포함되지 않는다. 앞으로 만들 배포 패키지의 내용까지 검증한 것은 아니다.

### 실제 공개 저장소·사이트 설정 확인

GitHub API를 읽어 확인한 현재 저장소는 공개 상태이며, Pages는 `main` 브랜치의 루트(`/`)에서 legacy 방식으로 배포한다. 확인한 원격 커밋은 `48820b60a64d312456219d40768597e3fc677160`이다. 공개 사이트의 기존 `assets/og.png`는 HTTP 200이며 로컬 파일과 SHA-256이 같다. 새 `assets/game/manifest.json`과 두 Blender 제작 스크립트의 확인 URL은 HTTP 404였다. 후속으로 현재 매니페스트에 있는 이미지 URL 25개도 모두 확인했으며 전부 HTTP 404였다. 이는 관찰한 시점의 해당 URL에서 파일을 제공하지 않았다는 증거이며, 모든 과거 배포·브랜치·외부 사본의 부재까지 입증하지는 않는다. [배포 관찰 기록](deployment-evidence.json)

이는 향후 배포가 자동으로 적합하다는 뜻이 아니다. **공개 저장소에 스크립트를 커밋하는 행위 자체도 공개 배포**이므로, 사이트용 빌드에서 제외하더라도 저장소에 공개하는 `bpy` 스크립트의 라이선스 조건은 별도로 처리해야 한다. 전체 작업 폴더를 올리는 방식과 게임 실행 파일만 사이트에 올리는 방식을 구분하여 새 배포 구성을 확정해야 한다. 이 점검에서는 커밋·푸시·Pages 설정 변경을 하지 않았다.

### OpenAI 생성 이미지·코드

한국 등 적용 지역의 개인용 Terms of Use는 법이 허용하는 범위에서 OpenAI와 사용자 사이의 결과물 권리를 사용자에게 귀속시키며, OpenAI가 가진 권리가 있다면 양도한다고 규정한다. 이를 근거로 게임 내 상업 이용을 검토할 수 있다. 동시에 입력의 권리 확보와 법 준수는 사용자의 책임이며, 결과물이 유일하지 않을 수 있고 비침해 보증도 제공하지 않는다. 따라서 **상업적 사용 근거가 있다는 것과 저작권 분쟁 가능성이 없다는 것은 다른 판단**이다. [OpenAI Terms of Use — Content 및 Disclaimer](https://openai.com/policies/row-terms-of-use/)

이 계정의 개인용·Business·Enterprise 계약 구분은 확인하지 않았다. 조직용/API 계약이면 해당 계약을 적용해야 하며, 보상·면책 조항의 적용을 추정하지 않는다. [OpenAI Services Agreement](https://openai.com/policies/services-agreement/)

조직용 계약 §4.1의 권리 귀속 상대방은 계약의 **Customer**다. 사용자가 본인 이름으로 상업화할 수 있는 권리를 확인하려면, 생성에 사용한 계정이 개인 계정인지 본인 사업자의 계정인지 회사 제공 계정인지 구분해야 한다. 계정의 계약 주체는 사용자 답변 대기 중이다. 이 기록은 개인 소유권이나 회사와의 권리 양도를 추정하지 않는다. [OpenAI Services Agreement — §4](https://openai.com/policies/services-agreement/)

Codex 등 코드 생성 결과에는 제3자 오픈소스 라이선스가 적용될 수 있다고 명시되어 있다. AI가 작성했다는 사실만으로 외부 코드 점검이 불필요해지지 않는다. [OpenAI Service Terms — §4](https://openai.com/policies/service-terms/)

별도의 Sharing & publication policy는 SNS 게시·라이브 스트리밍·OpenAI 제품 시연 등의 범위에서 AI 생성 사실을 분명히 표시하고 게시자에게 귀속시키도록 안내한다. 해당 방식으로 생성 이미지를 홍보에 게시할 때도 확인해야 한다. 이 문구를 모든 게임 화면에 특정 로고나 워터마크가 의무라는 뜻으로 확대하지 않으며, 현재 게임 화면에 AI 표시가 없다는 사실만으로 저작권 침해를 판정하지 않는다. [OpenAI Sharing & publication policy](https://openai.com/policies/sharing-publication-policy/)

이미지 원본의 C2PA `softwareAgent`에 `gpt-image`, `2.0`이 기록되어 있으나, 이는 정확한 서비스 모델 ID 확인이나 저작권 보증이 아니다. 서명을 암호학적으로 검증한 것은 아니다. 실제 생성 프롬프트와 자체 생성 이미지 참조 관계는 [이미지 생성 기록](../../art/recipes/imagegen-prompts.md)에 남겼다.

### 국내 AI 결과물 안내서와 권리 성립

한국저작권위원회의 「생성형 인공지능 결과물에 의한 저작권 분쟁 예방 안내서」는 생성 결과에 기존 저작물의 표현이 남을 수 있고, 영리 이용·외부 공개 전에 권리와 서비스 약관을 검토하도록 안내한다(인쇄 44–45쪽, PDF 45–46쪽). 따라서 광고를 붙이는 게임이라는 사용 목적을 포함하여 점검해야 한다. [위원회 공식 자료 모음](https://www.copyright.or.kr/notify/notice/view.do?brdctsno=55402)

별도의 「생성형 인공지능 활용 저작물의 저작권 등록 안내서」는 인간의 창작적 기여가 없는 AI 산출물 자체와, 인간이 창작적으로 추가·선택·배열한 표현을 구분한다. 단순 크기 변경·색 변경만으로는 기여 인정이 어렵고, 인정 여부는 구체적인 사실관계에 따라 판단한다(인쇄 12, 17–19, 22, 40쪽). 이는 상업 이용 자체를 일괄 금지한다는 뜻은 아니다. 현재 이미지·Blender 작업이 인간의 독점 저작권을 성립시켰는지는 이 감사에서 판단하지 않는다. [등록 안내서 원문](https://www.copyright.or.kr/notify/notice/download.do?brdctsfileno=27407&brdctsno=55402)

두 안내서의 발행일은 **2025-06-30**, 법률·판례 기준은 2025년 6월이다. 자료 모음 게시일인 2026-04-30을 안내서의 개정일로 취급하지 않았다. 문서의 해당 쪽 원문과 페이지 번호를 확인했으며, 원문 PDF를 게임 파일에 포함하지 않았다.

## 시각 검토의 범위

배경 원본 4장, 소품 21개의 연락판, 기존 공유 이미지를 검토했다. 가시적인 타사 로고·서명·워터마크·알아볼 수 있는 유명 캐릭터는 발견하지 못했다. 새 이미지의 프롬프트에는 특정 작가·프랜차이즈 이름이나 외부 판매자의 참조 이미지 입력이 없다. 외부 에셋 조사 문서는 상품 정보·제작 방향의 참고 기록이며, 판매처 파일을 게임에 넣었다는 기록은 아니다.

이 검토는 모든 기존 작품과의 유사성 검색, 전 세계 저작권·상표 조사, 저작권 귀속 판단을 포함하지 않는다. `Glintgrove` 명칭의 상표 사용 가능성도 별도 조사하지 않았다. README의 `Tetris Effect` 분위기 비교 문구는 게임 자체의 특징을 설명하는 문구로 바꾸는 것이 상업 홍보의 출처 혼동을 줄인다. 그 이름의 언급만으로 저작권 침해가 확인된 것은 아니다.

### 명칭 검색에서 발견한 외부 게임 콘셉트

워드마크의 정확한 문자열로 공개 웹을 검색한 뒤, Vedant Bhatnagar의 포트폴리오에서 **「Glintgrove: A Living Ecosystem (Game Concept Art)」**라는 작품 페이지의 제목과 본문을 확인했다(2026-09-13). 해당 페이지는 자연과 기계 생물이 공존하는 게임 콘셉트와 네 캐릭터를 소개한다. 공개 페이지의 존재는 확인했으나 실제 출시·상표 등록·정확한 최초 공개일을 확인한 것은 아니다. [작가의 프로젝트 원문](https://vedantbhatnagar24.artstation.com/projects/2BAeDY)

**동일한 이름의 외부 게임 콘셉트가 존재한다는 구체적인 단서**이므로, `Glintgrove`가 미사용·독점 가능한 이름이라고 보장할 수 없다. 이름이 같다는 사실만으로 그림의 복제나 저작권·상표권 침해를 확정하지 않는다. 사용자 프로젝트의 기존 명명 경위나 이 외부 작품과의 관련성은 확인되지 않았다. 이 점은 이미지 파일 라이선스와 구분하여 서비스 지역별 상표·명칭 검토 대상으로 남긴다. 확인 없이 일괄 이름 변경이나 침해 판정을 하지 않았다.

프로젝트의 텍스트 설명은 확인했지만 비교 가능한 그림 원본은 확보하지 못했다. 일반 HTTP 요청은 403을 반환했고 검색에서도 해당 작품 이미지를 확보하지 못했다. 별도 검토자의 후속 도구 접근도 실패하여, 성공한 본문 확인의 제목·탐색 경로·요약과 이 접근 한계를 [명칭 검색 기록](name-search-evidence.json)에 보존했다. 따라서 **해당 작품과 현재 그래픽을 시각적으로 대조 완료했다고 주장하지 않는다.** 이 외부 작품의 이미지·모델을 게임에 새로 반입하거나 생성 도구에 입력하지 않았다.

## 배포 전 남은 확인

1. **기존 제작 경위 확인:** 기존 코드, 첫 30개 레벨, 아이콘, 공유 이미지를 직접 만들었는지, AI 도구·외부 원본·공동 제작자가 있었다면 무엇인지 확인한다. 필요한 원본 링크·라이선스·권리 양도 기록을 추가한다. 출처를 확인할 수 없는 파일은 자체 제작물로 교체하는 편이 관리하기 쉽다.
2. **실제 배포 파일 확정:** HTML/CSS/JS, 설정·웹 매니페스트, 사용 이미지, 필요한 고지 등 서비스 파일만 묶는다. 로컬 가상환경·Blender 프로그램·제작 도구를 배포 대상에 넣지 않는다. 제작 스크립트를 공개 저장소로 배포하려면 앞의 Blender API 라이선스 조건을 처리한다. 서비스 워커 캐시에서 제외된 것만으로 서버 공개까지 차단되는 것은 아니다.
3. **AI 결과물의 이용 기록 보존:** 원본·프롬프트·참조 관계·생성일·적용 계약·최종 파일 해시를 보존한다. 사람이 실제로 편집한 기여는 작업 파일·변경 이력으로 남긴다. 배경을 '100% 사람이 직접 그린 독점 원화'라고 표기하지 않는다.
4. **최종 서비스의 권리 검토:** 서비스 지역·계약 주체를 확인한 후, 현재 명부와 기존 제작 자료를 바탕으로 저작권 전문가에게 출시 전 검토를 받는 것이 사용자가 요청한 엄격한 위험 관리에 적합하다. 본 점검으로 분쟁 가능성 0을 보장할 수는 없다.
5. **명칭 관련 단서 확인:** 위 동일 명칭 게임 콘셉트와 기존 이름 선정 경위를 확인하고, 배포할 지역에서 이름·상표 사용 가능성을 별도로 검토한다. 이름의 일치가 곧 이미지의 저작권 침해라는 뜻은 아니다.

현재는 한국을 중심으로 공식 자료를 확인했으며 서비스 지역과 기존 제작 경위는 사용자 답변 대기 상태다. 이번 점검에서 실제 서비스 배포, 외부 에셋 구매, 유료 생성 API 호출, 전체 게임의 오픈소스 라이선스 지정은 하지 않았다.

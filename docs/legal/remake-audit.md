# Ilyndrel 시각 요소 재제작 기록

작업일: 2026-09-13. 사용자의 ‘문제가 되는 부분을 모두 직접 다시 제작’ 요청에 따른 교체 기록이다. 이전 `history/2026-09-13-before-remake/`의 조사와 명부는 교체 전 스냅샷이며 현재 파일의 해시·제작 경위를 나타내지 않는다.

보관 경로 갱신(2026-09-14): 아래의 `art/build/`·`art/retired/`와 ‘Git 제외’는 당시 상태를 기록한 것이다. 해당 자료는 현재 `art/history/2026-09-14-complete-work/production/`·`retired/`에 Git으로 보존하며, 원래 경로와 바이트 일치는 [보관 명부](../../art/history/2026-09-14-complete-work/inventory.json)에서 확인한다. 과거 실행 명령·관찰·검증 수치는 유지한다. 미사용 구버전 WebP·WAV는 현 에셋 폴더에서 정리했지만 [커밋 e355b1b](https://github.com/inininax/glintgrove/commit/e355b1b8ffa46d2047dcbd427fa20ebb37c5c6a0)에 보존되어 있고, 현재 PNG·Blender 원본·악보·생성기는 제작 폴더에 남아 있다. 보관 자료는 서비스용 빌드에서 제외한다.

이 문서의 아래 수치·교체 범위와 통합 검증은 최초 재제작 시점의 기록이다. 이후 배경 개선에서는 v2 원본을 보존하고, 같은 로컬 장면에 조명·물길·수면 재질을 추가한 v3 배경을 제작했다. 그 다음 사용자의 명시적인 GPT 생성 요청으로 숲 한 장을 이미지 생성 도구로 다시 만들고, v5에서는 먼 숲의 명암과 밀도를 다듬었다. 타이틀 상징·게임명도 텍스트 프롬프트로 새 이미지를 생성했다. 현재 이미지 구성은 GPT 숲 1개, GPT 타이틀 이미지 2개, Blender 배경 3개와 소품 21개이며, 아래의 ‘이미지 모델 출력 없음’은 최초 재제작 당시만의 관찰이다.

현재 타이틀·숲의 정확한 프롬프트와 제작 방식은 [새 제작 기록](../../art/recipes/title-forest-music.md), 참조 체인의 이전 단계는 [GPT 숲 v4](../../art/recipes/gpt-forest-v4.md)와 [Blender v3](../../art/recipes/procedural-environments-v3.md)에 있다. 배경의 느린 물빛·안개·반딧불은 Canvas 코드로 표현하며, 새 그림 자체는 정지 이미지다. 별도의 [72초 배경음악](../../art/recipes/forest-reverie-v1-music.md)은 외부 녹음·샘플·가사·보컬 없이 프로젝트의 악보와 수학적 합성기로 제작했다. 이미지 생성 도구와 음악 합성기의 제작 방식을 혼동하지 않는다.

[교체 파일 명부](replacement-register.json)는 현재 이미지·사이트 WebP·음악·악보·합성 코드의 해시를 기록한다. GPT v5 → GPT v4 → Blender 참조/원본 체인을 재귀적으로 확인하고, 이미지 참조가 없는 타이틀은 명시적인 빈 참조 목록과 프롬프트·출력 해시를 확인한다. 타이틀 WebP는 저장된 내보내기 해시까지 비교한다. 음악은 WAV·악보·합성기 해시와 PCM 헤더·길이를 비교한다. 이 검사는 기록과 파일의 일치 여부에 한정되며 생성 서비스·정확한 모델 버전·권리 귀속을 독립적으로 증명하지 않는다. [배경·안내창 검증](../art/living-background-verification.md)은 v4 이전의 동작 확인 범위를 기록한다.

현재 타이틀의 화면 크기별 확인, 72초를 넘긴 동일 오디오 소스의 반복 재생, 음소거·애니메이션·캐시 동작은 [타이틀·숲·음악 검증](../art/title-forest-music-verification.md)에 구분해 기록한다.

## 고대 숲·장치 가독성 개선

현재 숲은 v4 원본을 편집한 GPT v6이며, 석문 3개는 Blender 5.2.1에서 새로 모델링·렌더한 v2 원본으로 교체했다. R/G/B 표시는 일관된 색·형태 표식으로 바꾸고 무료 장치 안내를 추가했다. 배경음악은 새 96초 v2 악보와 합성기를 사용한다. 이전 절의 v5·72초 설명과 검증 문서는 해당 개선 시점의 기록으로 보존한다. 현재 제작·참고 자료·원본은 [고대 숲 기록](../../art/recipes/ancient-forest-v6.md)에 있다. 외부 조사 이미지는 생성 입력이나 배포 에셋으로 반입하지 않았다.

## 보석 타이틀 개편

2026-09-14 보석 타이틀 개편에서는 현재 사이트 타이틀을 v2 게임명 하나로 교체했다. 위의 두 타이틀 이미지·참조 없는 생성 설명은 이전 v1 기록이다. v2는 자체 v1 게임명과 숲 v6를 참고한 디자인을 만들고 내장 이미지 도구로 검정 배경 버전을 생성했다. 실제 RGB 파일을 CSS screen으로 합성하며, 알파 투명 이미지라고 기록하지 않는다. 이전 상징·게임명은 현재 배포에서 제외하고 원본만 보존한다. [보석 타이틀 제작·갱신 기록](../../art/recipes/jeweled-title-v2.md)에 전체 참조 체인과 정확한 프롬프트가 있다.

## 범위와 한계

새 제작 경위가 확인된다는 것은 사람이 직접 수작업으로 만들었다는 뜻이나, 독점적인 저작권이 성립했다는 뜻이 아니다. 생성 계정이 회사 제공 계정이라면 계약상 권리 귀속은 다시 만드는 행위만으로 바뀌지 않는다. 사용자와 고용주·공동 제작자 사이의 계약은 이 작업에서 확인하지 못했다.

이 작업은 시각 표현과 퍼즐 콘텐츠를 교체했다. 게임 규칙, 기존 시뮬레이션·저장·인프라 코드의 모든 줄을 다시 작성하는 작업이나 과거 Git 이력을 지우는 작업이 아니다. 기존 기술 코드의 소유권을 확인했다는 주장은 하지 않는다. 출처가 확인된 Public domain 난수 구현은 고지를 유지한다.

새 이름의 정확한 문자열 `"Ilyndrel" game`, `"일린드렐"` 공개 검색에는 일치 결과가 없었다. 이는 2026-09-13의 제한된 검색 결과이며 등록 상표 조회나 전 세계 명칭 사용 가능성 확인이 아니다. 저장소 경로·공개 URL·진행 데이터 키의 옛 문자열은 호환성 때문에 유지하며 화면 브랜드와 구분한다.

교체된 원본·이전 출력·예전 검토 화면은 `art/retired/`로 분리하고 Git과 서비스 묶음에서 제외한다. 이미 공개된 사이트나 과거 커밋의 파일은 배포·이력 변경 없이 그대로일 수 있다. `npm run build`는 현재 실행 파일과 현재 매니페스트의 이미지만 `dist/`로 복사하며 업로드하지 않는다.

## 폴더·관리 기능·동작 수정

[폴더 트리](../../FOLDERS.md)는 `src/` 코드, `assets/game/` 게임 이미지, `assets/site/` 사이트·타이틀 이미지, `assets/audio/` 재생용 음악, `art/source/` 편집 원본·악보, `art/renders/sprites/` 지속 보관하는 렌더 PNG, `tools/` 로컬 제작 도구를 구분한다. 필수 소품 PNG 21개를 Git 제외 임시 폴더에서 정식 렌더 폴더로 이동했다. 파일 이동 전후 이미지 내용의 해시가 동일함을 확인했다.

관리자 웹·관리자 계정·서버 관리 API는 확인되지 않았다. 별도 관리자 화면을 새로 만들지 않았다. 개발용 갤러리와 브라우저 테스트는 `tools/`에 두고 일반 사용자용 `dist/`에서 제외한다. `?debug=1` 내부 핸들도 루프백 주소에서만 제공한다. 현재 게임의 진행 데이터는 기기 내 저장이며 서버의 타 사용자 정보를 관리하는 기능은 없다.

첫 클리어 모달 상태와 서비스 워커의 오래된 코드 재캐싱을 수정했다. 음향은 실제 사용자 입력에서 오디오 컨텍스트를 활성화하도록 수정했다. 실제 브라우저 클릭 후 오디오 컨텍스트 running, 신호 RMS 약 0.0398을 확인했고, 끄기에서 출력 0·다시 켜기에서 배경음 신호 복원을 관찰했다. 물리적인 스피커 출력을 직접 청취한 검증은 아니다.

플레이 중 설정에서 조각 아트/간결한 도형, 움직임, 색상 보조, 빛 테마를 바꿀 수 있다. 모바일에서 전환 전후 판·이동 수·거울 방향 유지와 다음 단계·재플레이 첫 클리어 모달을 실제 포인터 입력으로 확인했다. 소리·표시 방식의 동작 검증은 파일 저작권 검토를 대신하지 않는다.


## 최초 재제작 작업본 확인

- Node 회귀 테스트 83개, Python 아트 도구 테스트 20개 통과. 300개 레벨 모두 풀이 가능하며 새 시드에서 동일하게 재생성된다.
- 브라우저 통합 검사 20개 통과. 모바일 390×844에서 첫 클리어→다음 단계→재플레이→다음 단계가 모두 완료 모달을 표시했다.
- 관리자 기능은 없으며 개발 화면과 진단 핸들을 일반 배포 경로에서 구분했다.
- `npm run build`는 실행 파일 70개와 파일 목록 1개만 묶었다. 제작 원본·도구·이전 이미지·조사 자료는 포함하지 않았다. 현재 작업본은 커밋·푸시·서비스 배포하지 않았다.
- 소품 원본 PNG 21개와 배경 원본 PNG 4개 모두 Git에 포함 가능한 경로에 있다. 임시 `art/build/`가 없어도 현재 카탈로그의 입력 25개가 존재한다. 아직 커밋하지 않았으므로 기존 원격 커밋만 복제하면 이 새 파일들은 포함되지 않는다.
- 이전 자료 88개는 로컬 `art/retired/`로 분리했다. 공유 이미지 원본의 로컬 경로·시간 메타데이터는 서비스용 PNG에서 제거했으며 압축 픽셀과 디코딩 픽셀의 동일성을 확인했다.

최초 재제작 시점의 생성 파일에서 외부 판매처 모델·텍스처·폰트·아이콘 팩이나 이미지 모델 출력이 남아 있는 런타임 의존성을 발견하지 못했다. 이후 추가한 GPT 숲과 타이틀 이미지는 이 문서 첫머리의 현재 구성에 해당한다. 설치된 시스템 글꼴의 일반 표시와 Public domain 난수 구현은 위 고지 범위로 남는다. 이는 기존 코드의 권리 귀속·새 이름의 상표 사용 가능성·전 세계 비침해에 대한 보증으로 확대하지 않는다. 계정 또는 고용 관계의 계약상 권리 귀속은 파일 교체로 확인되는 사항이 아니다.

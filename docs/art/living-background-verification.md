# 배경·안내창·기본 언어 검증

작업일: 2026-09-13. 앞선 재제작 이후 요청한 배경 개선과 애니메이션, 중복 안내창 수정, 한국어 기본값 변경의 기록이다.

## 변경

- Blender v2 원본을 보존하고 별도 v3 원본에 달빛·역광·물길·잔물결 재질을 추가했다. 제작 명령과 파일 출처는 [v3 레시피](../../art/recipes/procedural-environments-v3.md)에 있다.
- 캐시된 배경 → Canvas 빛·안개·반딧불·수면 효과 → 보드 → 퍼즐 기물 순서로 그린다. 제목과 지도에서도 배경이 움직인다.
- 설정의 `배경 움직임과 반짝임`을 끄거나 OS의 모션 감소를 켜면 배경은 현재 프레임에 멈춘다. 다시 켜도 초기 위치로 튀지 않는다.
- 장치 튜토리얼과 하단 설명을 동시에 띄우던 경로를 제거했다. 안내창은 입력을 차단하는 대화상자이며, Tab 포커스 유지·Esc 닫기·보이는 게임 버튼으로 포커스 복귀를 지원한다.
- 새 저장 데이터와 언어 값이 없는 이전 데이터는 한국어를 사용한다. 명시적으로 선택한 영어·자동 설정, 진행도와 별 기록은 유지한다. HTML과 웹 앱 매니페스트의 기본 언어도 한국어다.

## 실제 Ego 브라우저 확인

사용자 진행 데이터와 분리된 로컬 8015 포트에서 테스트했다.

| 확인 | 결과 |
|---|---|
| 지도에서 처음 17번 퍼즐 진입, 614×427 | 대화상자 1개, 토스트 없음, 확인 버튼 가림 없음 |
| 390×844 및 높이 320px | 카드가 화면 안에 위치하며 짧은 화면에서 내부 스크롤 가능 |
| 안내 중 H/U/R, Tab/Shift+Tab | 게임 이동·힌트 미변경, 확인 버튼에 포커스 유지 |
| 안내 닫기 | 보이는 도움말 버튼으로 포커스 복귀, 이후 H 힌트 정상 작동 |
| 영어 선택 후 새로고침 | 영어와 진행도 유지 |
| 영어 브라우저의 명시적 자동 선택 | 영어 표시, 이후 한국어 선택 정상 |
| 레벨을 시작하지 않은 제목 | 배경 시계가 진행함 |
| 움직임 끄기, 30프레임 비교 | 배경 시계와 Canvas 픽셀 해시 동일 |
| 움직임 켜기, 30프레임 비교 | 배경 시계와 픽셀 해시 모두 변경 |
| OS 모션 감소 실시간 적용 | 배경 시계와 픽셀 해시 동일, 현재 프레임 유지 |

Node 전체 회귀 테스트 99개 통과. 별도 검토자가 배경 캐시 재사용·그리기 순서·동작 설정과 한국어 저장 마이그레이션을 검토했다. 브라우저 통합 테스트는 첫 안내 → 실제 거울 클릭 → 첫 완료 모달, 300개 레벨의 힌트·광선, 마지막 퍼즐 풀이, 일일 도전과 튜토리얼 재방문 등 25개 항목을 통과했다.

## 최종 아트·빌드 확인

- 최종 매니페스트 `nocturne-98ecd1f455b6`: 이미지 25개, 2,301,218 bytes. 새 배경 4개는 각각 1536×1024이며, 기존 소품 21개를 유지했다.
- Python 아트 도구 테스트 20개와 `check:assets` 통과. 배경 4장의 WebP를 원본에서 재인코딩한 결과가 실제 서비스 파일과 바이트 단위로 같음을 별도 검토자가 확인했다.
- v3 원본·부모 원본·출력·스크립트와 기록된 코드 45개 파일 해시를 검토했다. 독립된 임시 복사본에서 원본 변경·부모 변경·원본 누락·알 수 없는 경로 등을 검사한 11개 출처 기록 회귀 확인도 통과했다. 실제 작업 폴더의 원본은 이 검사에서 변경하지 않았다.
- `npm run build`로 현재 실행 파일 70개와 파일 목록을 갱신했다. 이 변경 묶음은 로컬에 적용했으며 별도 커밋·푸시는 수행하지 않았다.
- 애니메이션과 안내창의 실제 브라우저 검증은 최종 배경을 게시하기 전에 완료했다. 최종 v3 이미지는 원본 렌더를 직접 시각 확인했다. 마지막 브라우저 합성 화면을 다시 캡처하는 단계에서 Ego 제어권이 사용자에게 넘어와 추가 조작을 중단했다. 위 검증 범위를 최종 이미지와 결합한 화면의 추가 확인까지 확대하지 않는다.

이 기록은 확인한 동작과 제작 경로의 증거이며 파일의 저작권 비침해를 보증하는 문서가 아니다. 제작 원본·도구·이 검증 문서는 일반 사용자용 `dist/`에 포함하지 않는다.

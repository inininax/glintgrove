# 아트 스튜디오

로컬 서버를 실행한 뒤 [아트 스튜디오](../../tools/art-preview.html)를 엽니다. 배경·소품·사이트 이미지·음악을 함께 살펴보는 제작자용 조회 도구입니다. 별도의 관리자 계정이나 인증 서버가 없고, 파일 수정·업로드 기능은 제공하지 않습니다. 게임의 일반 사용자 화면에는 진입 버튼을 두지 않습니다.

## 볼 수 있는 것

현재 게임 매니페스트와 원본 카탈로그에서 배경 4개와 소품 21개를 읽습니다. 사이트에는 보석 게임명·아이콘·공유 이미지 3개, 음악에는 현재 96초 배경음악 1개를 표시합니다. 현재 총 29개이며 게임 매니페스트가 바뀌면 배경·소품 목록도 함께 바뀝니다.

- 이름·식별 이름·파일 경로로 검색하고 종류를 선택할 수 있습니다. 검색과 종류 필터를 함께 적용할 수 있습니다.
- 이미지 또는 상세 보기 버튼을 누르면 큰 미리보기와 크기, 현재 배포 경로, 제작 원본, Blender 원본, 제작 기록을 확인할 수 있습니다. 이미지 원본은 같은 창에서 전환해 비교합니다.
- 현재 선택한 이미지의 바로 보기와 다운로드를 제공합니다. `.blend`와 악보 JSON은 원본 링크로 엽니다. 이 도구가 해당 원본을 자동 편집하거나 렌더하지는 않습니다.
- 소품은 왼쪽에 게임 셀 안의 실제 표시, 오른쪽에 잘라내지 않은 전체 원본을 표시합니다. 설정을 펼쳐 셀 크기와 미리보기 바탕을 바꿀 수 있습니다.
- 보석 게임명은 실제 알파가 없는 RGB 이미지입니다. 게임처럼 검정 매트를 screen으로 합성하며, 원본 파일을 투명 이미지로 바꾸지 않습니다.
- 음악은 재생을 눌렀을 때 로드합니다. 자동 재생하지 않으며 반복 재생을 끌 수 있습니다. 새 플레이어를 재생하면 다른 미리 듣기는 멈춥니다. 검색·목록 새로고침 시 기존 미리 듣기도 멈춥니다.
- 광선·도착 후광·반짝임은 독립된 PNG가 아니라 런타임 렌더 코드입니다. 안내 영역의 실제 게임과 관련 코드 링크에서 확인합니다.

확대 창은 키보드로 열 수 있고, Tab과 Shift+Tab은 첫 항목과 마지막 항목 사이에서 순환합니다. 음악의 브라우저 기본 컨트롤 내부 이동은 그대로 둡니다. 닫기·Escape·창 바깥 클릭으로 닫으면 원래 실행 버튼으로 초점이 돌아옵니다. 작은 화면에서는 확대 창 내부를 스크롤하며, 가로로 긴 이미지는 비율에 맞춰 미리보기 높이를 줄입니다.

## 갱신과 실패 처리

배경·소품은 게임과 같은 `AssetStore`를 사용합니다. 로딩에 실패한 교체는 이전 정상 이미지를 유지하고, 어떤 항목이 이전 이미지인지 알립니다. 현재 배포 경로와 표시 중인 이전 파일이 다르면 상세 창에 두 경로를 따로 표시합니다. 카탈로그를 읽지 못해도 이전 정상 카탈로그를 유지합니다. 사이트 이미지도 교체 실패 시 이미 읽은 정상 이미지를 유지합니다.

제작 파일을 수정한 뒤 해당 생성기·내보내기를 실행하고 목록 새로고침을 누르세요. 아트 제작 과정은 [아트 안내](../../art/README.md), 배포와 폴더 역할은 [폴더 안내](../../FOLDERS.md)를 따릅니다. 사이트 이미지의 명시적인 경로 목록은 `tools/art-preview.js`의 `siteDefinitions`에 있습니다. 사이트 브랜드 버전을 교체할 때 실행 화면·배포 목록과 함께 이 목록도 갱신합니다. 음악 경로와 길이는 실행 로더의 상수를 함께 사용합니다.

카탈로그 문자열은 HTML로 삽입하지 않고 텍스트로 표시하며, 파일 링크는 저장소 내부의 정해진 폴더에 한정합니다. 도구 자체는 `tools/` 안에 있고 GitHub Pages·실행용 `dist/`에서는 제외됩니다. 이 페이지는 인증된 온라인 관리자 서비스가 아닙니다. 제작 원본을 외부에 공개하지 않으려면 저장소 루트 전체를 그대로 웹 서버에 게시하지 마세요.

## 구현과 확인 범위

구현 파일은 `tools/art-preview.html`, `tools/art-preview.css`, `tools/art-preview.js`입니다. 외부 폰트·아이콘·UI 라이브러리 의존성은 추가하지 않았습니다. 이 작업은 게임 로직이나 저장 데이터를 수정하지 않습니다.

작성 단계에서는 JavaScript 구문·로컬 링크와 메타데이터 경로·기존 AssetStore 회귀 검사를 확인합니다. 실제 화면 크기, 모달 키보드 동작, 원본 전환과 음악 재생은 통합 담당자가 기존 Ego 창에서 별도로 확인합니다. 이 문서는 제작 단계의 기록이며 독립 검토 승인을 대신하지 않습니다.

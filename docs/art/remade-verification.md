# Ilyndrel 현재 작업본 검증

검증일: 2026-09-13. 로컬 작업본과 로컬 `dist/` 미리보기의 결과이며 공개 서비스 배포 확인서는 아니다.

음향·게임 상태 15개 검사는 별도 검토자가 다시 실행했다. 배포 도구의 실패 시 기존 결과 보존, 예상 밖 파일 보존, 심볼릭 링크 거부, 이미지 검증, 매니페스트 일관성도 별도 검토자가 격리된 임시 디렉터리에서 확인했다. [독립 검토 기록](../legal/remake-independent-review.md)을 함께 참고한다.

## 실제 브라우저 관찰

Ego Browser의 동일 작업 공간에서 소스 미리보기 `http://127.0.0.1:8013/`와 배포 미리보기 `http://127.0.0.1:8014/`를 사용했다. 검사를 위한 내부 핸들은 이 루프백 주소의 `?debug=1`에서만 제공된다.

- 모바일 390×844에서 실제 포인터 입력으로 1단계 클리어 → 2단계 첫 클리어 → 2단계 재플레이 클리어 → 3단계 첫 클리어를 진행했다. 각 완료 모달이 표시됐다.
- 게임 중 설정에서 조각 아트를 간결한 도형으로 바꾸고, 빛 테마·움직임·색상 보조를 변경했다. 변경 전후 레벨, 이동 수, 거울 방향은 유지됐다. 화면 가로 넘침은 없었다.
- 실제 시작 버튼 클릭 전에는 오디오 컨텍스트가 없었다. 클릭 후 컨텍스트 `running`, 마스터 게인 0.62, 배경음 활성 상태와 출력 신호 RMS 약 0.039798·피크 약 0.081195를 관찰했다. 소리 끄기에서 신호 0, 다시 켜기에서 배경음 신호 복원을 확인했다. 물리 스피커를 직접 청취한 검사는 아니다.
- 배포 묶음의 시작 상태는 `ok`, 아트 상태는 `ready`, 이미지 25개 모두 디코딩 완료, 실패 0개였다. 해당 관찰에서 외부 리소스 요청은 없었다.
- 배포 서버에서 개발 갤러리·브라우저 E2E·Blender 원본·보관 기록·법무 문서·이전 아이콘/공유 이미지·`/admin`은 404였다. 새 `assets/site/icon.svg`와 `assets/site/share.png`는 200이었다. 관리자 계정이나 관리 API는 코드 조사에서도 발견되지 않았다.

## 시각 검토 자료

화면 캡처는 `art/previews/remade-title-desktop.png`, `remade-game-mobile.png`, `remade-settings-mobile.png`, `remade-simple-mobile.png`, `remade-win-mobile.png`에 있다. 단어 없는 Blender 소품 모음은 `sprite-contact-sheet-v1.jpg`이다. 화면 캡처의 일반 텍스트는 브라우저가 설치된 시스템 글꼴로 표시한 결과이며 폰트 파일을 배포한 것이 아니다. 이 여섯 검토 이미지는 서비스 묶음에서 제외한다.

## 파일 출처와 재제작 가능성

현재 카탈로그 입력 PNG 25개는 모두 존재하고 Git에 포함 가능한 경로에 있다. Blender 원본 2개, 제작 스크립트, 원본과 배포 이미지, 검토 이미지의 SHA-256은 [현재 파일 명부](../legal/replacement-register.json)에 기록한다. 교체 전 자료 88개는 로컬 보관 위치와 해시가 일치하며 Git과 배포에서 제외된다. 공유용 PNG는 원본의 압축 픽셀·디코딩 픽셀을 유지하면서 로컬 경로·시간 등 텍스트 메타데이터만 제거했다.

출처 기록 도구는 기존 제작 증거의 원본·마스터 해시와 일치할 때만 해당 제작 경위를 연결한다. 새 파일의 저작권을 자동 승인하지 않으며, 변경한 원본·마스터는 재검토 대상으로 기록한다. SVG 저작 경위, 화면 캡처 출처, 배포 변환 결과의 확인은 이 기록 도구의 자동 검증 범위와 구분한다. 로컬 보관함이 없는 새 작업 폴더에서는 기존 명부의 보관 이력만 유지하고 로컬 보관 파일을 검증하지 않았다고 표시한다.

이 검사는 실행 동작, 제작 경위, 파일 일치와 배포 범위를 확인한다. 기존 코드의 권리 귀속, 계정·고용 계약, 상표 사용 가능성이나 모든 기존 작품에 대한 비침해를 증명하지 않는다. 커밋·푸시·공개 배포는 실행하지 않았다.

# Remade interface and Canvas artwork

Authored 2026-09-13 for Ilyndrel (일린드렐), following the instruction to replace visual material whose creation history could not be established. This is a production record, not a guarantee of exclusive copyright, trademark clearance or zero legal risk.

## Newly authored components

- `src/ui/symbols.js`: a geometric seed emblem, an eight-sided light rating mark, play, hint, undo, reset, map, lock, pointing-hand, splitter, crystal, portal and settings controls, and nine achievement emblems. Every SVG path in this module was written during this remake without an outside icon library, tracing input or downloaded graphic. `index.html` includes those same paths for its immediately visible controls and ornaments.
- `assets/site/icon.svg`: a new app icon with an asymmetric seed, inset octagonal border and small light lozenge. The favicon now uses this file instead of the former embedded circle. The file has no text outlines, font embedding or external references.
- `css/style.css`: a new interface composition using teal stone surfaces, brass seed ornaments, chapter leaves and cut-corner controls. The new title and in-game wordmark remain ordinary live text using installed system fonts. Displaying that text does not mean the font glyphs were authored for this project. No font file or emoji artwork is bundled.
- `src/ui/ui.js`: level ratings, locked levels, tutorial pictures and achievement artwork now use the original SVG symbol module. The existing dialog and event behavior remains in place. Star ratings retain accessible numeric descriptions; pictographs are decorative to assistive technology.
- `src/render/background.js`: a newly drawn chamfered stone board, individual inlaid cells, seed marks, three-piece fallback wall rocks, curved branching woodland when background images are unavailable, and drifting paired seed motes. The published background images are still loaded through the asset store when available.
- `src/render/entities.js`: new fallback recipes for emitter, mirror, splitter, crystal, gate, portal, tree, flower, mushroom and owl; new lens faces, source-direction marks, portal pair notches, awakened seed husks, resting marks, color badges and hint corners. Color badges construct small R/G/B letters directly from simple strokes, without a font-outline source. The existing Blender sprites continue to supply the normal object view. Grid coordinates and orientation semantics are unchanged.
- `src/render/beams.js`: optical threads with a narrow colored core, optional distinguishing dash patterns, moving lozenges and curved portal connections. No outside effect image or shader package is used.
- `src/render/bloom.js`: short event diffusion using two scaled Canvas copies, with no imported light texture.
- `src/render/renderer.js`, `layout.js`, `gradientCache.js`: newly written composition and context-local rendering helpers that preserve the engine interfaces. These utilities are not additional image assets.

The remake was authored using the existing game interfaces and gameplay rules as integration constraints. The older graphics were inspected to locate those interfaces and to identify the replacement scope; this was not a separate team with no access to prior code. No existing third-party logo, character, game artwork or icon collection was used as a drawing reference in this pass. General geometry, mathematical grid fitting and platform APIs are used throughout.

## In-game settings

`index.html` now exposes `btn-settings-game` in the live puzzle HUD. Its symbol is the new three-track settings mark. On widths up to 480px, the heading and move count occupy one row and five controls occupy a second row; layout reserves 138px above the board. The settings modal now includes a bilingual Display style selector (`set-display`): **Sculpted art** (`sculpted`, default) uses the 21 Blender sprites and background artwork; **Simple geometry** (`simple`) draws the newly authored Canvas representations and procedural backdrop. The display mode travels through the renderer layout and explicit drawing options; it does not mutate a global asset switch. The background cache key includes the selected mode, so changing it rebakes the board immediately. Existing saves missing the field use Sculpted art. The form emits `displayMode`; the main-application workstream persists it and applies changes during the current game. Switching does not restart the level or alter moves, orientations, trace or undo history.

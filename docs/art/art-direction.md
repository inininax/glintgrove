# Nocturne · the waking grove

Glintgrove의 숲이 주인공이고 인터페이스는 그 숲으로 들어가는 문이다. 고목·이끼·안개의 섬세한 배경과, 작은 화면에서도 구분되는 조각 같은 소품을 결합한다.

- 배경: 전경의 나무와 잎 → 낮은 이끼·돌 → 안개 → 먼 수관의 깊이. 중앙은 퍼즐을 위한 여백. 숲, 안개 심연, 별빛 정원, 고대의 심장 4개 테마를 유지한다.
- 소품: 공통의 청록 석재와 오래된 황동 테두리, 부드러운 직교 투영. 나무·생물은 위에서 조금 내려다보는 시점, 광학 기구는 회전 판독성을 위해 수직 시점. 거울의 받침은 고정되고 반사면만 회전한다.
- 빛: 가는 금빛 중심과 넓지만 옅은 후광. 색광의 색상·무늬가 흰 번짐에 묻히지 않는다. 클리어의 밝기 변화는 일시적이며 장면 전체를 지속적으로 탈색시키지 않는다.
- 활력: 잠든 상태는 차가운 석청색, 깨어나면 따뜻한 눈동자·꽃잎·생장색을 드러낸다. 과거에 깨어났으나 현재 연결이 끊긴 대상은 어둡게 표시해 승리 조건을 혼동하지 않는다.
- UI: 상아색 세리프 제목, 작은 산세리프 안내, 얇은 황동 선과 절제된 식물 문양. 화면 안에서 제작 도구나 내부 에셋 용어를 노출하지 않는다.

## 업그레이드 시 확인할 기준

1. 거울 `/`와 `\`, 분할기, 발산원, 문, 수정, 포탈과 장애물을 작은 칸에서도 구별할 수 있는가?
2. 나무의 잎·그림자가 옆 칸과 빛 경로를 침범하지 않는가? 교체한 이미지의 기준점이 원본과 맞는가?
3. 색상 요구를 색뿐 아니라 문자로도 읽을 수 있는가? 효과 끄기에서 지속적인 장식 운동이 멈추는가?
4. 타이틀·레벨 목록·설정·클리어 화면·390px 휴대전화에서 글자가 겹치거나 잘리지 않는가?
5. 그림 파일이 없거나 손상되었을 때 게임이 계속 동작하고, 이전 정상 이미지 또는 기본 도형이 나타나는가?
6. `.blend`를 직접 수정한 뒤 렌더할 수 있으며, 재생성 스크립트가 수작업을 뜻하지 않게 덮어쓰지 않는가?

‘모든 디자이너의 결과를 상회’하는지는 객관적으로 보장할 수 있는 지표가 아니다. 실제 실행 화면의 완성도·판독성·통일성과 반복 편집 가능성을 검토 기준으로 삼는다.

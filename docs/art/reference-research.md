# Glintgrove 아트 참고 조사

> 초기 제작 방향을 정한 이력 문서입니다. 아래 이미지 생성 계획과 일부 예전 표현은 이후 변경되었습니다. 현재 배경·공유 이미지는 자체 Blender 장면으로 교체했으며, 최종 참고 범위는 [재확인 기록](commercial-reference-recheck.md), 현재 제작물은 [재제작 기록](../legal/remake-audit.md)을 기준으로 봅니다.

확인일: **2026-09-13**. 대상: 기존 Canvas 2D 빛 퍼즐을 위한 독자적인 밤의 숲 아트.

외부 에셋 제작자의 공식 상품 페이지 7개를 선정해 숲의 구성 요소, 소재, 마법 소품, UI와 VFX를 비교했다. 전 세계 에셋을 빠짐없이 조사한 목록은 아니다. 가격은 확인 당시 표시값이며 실제 구매 견적이 아니다.

이번 제작의 추가 결제 예산은 **0원**이다. 이 조사에서는 상품 구매, 유료 다운로드, 외부 에셋 바이너리 반입을 하지 않았다. 아래 링크는 참고 자료이며 `assets/`에 가져온 에셋의 출처 목록이 아니다. 실제 게임용 이미지는 독자적인 Blender 모델·재질·렌더와 독자적인 설명을 사용한 이미지 생성으로 제작한다. 유료 상품의 모델, 텍스처, 화면 이미지를 추출하거나 생성 도구의 입력으로 사용하지 않는다.

각 항목의 **확인 사실**은 제작자의 공개 설명과 가격·라이선스 표시를 요약했다. **적용 판단**은 그 사실을 바탕으로 한 Glintgrove의 설계 제안이며 제작자의 조언을 인용한 것이 아니다.

## 1. Quaternius — Stylized Nature MegaKit

- 공식 출처: [제품 소개](https://quaternius.com/packs/stylizednaturemegakit.html), [제작자 itch.io 상품 페이지](https://quaternius.itch.io/stylized-nature-megakit).

- 적용 판단: 나무 하나의 복잡도보다 수관·관목·바위·지피 식물의 조합과 변형이 숲의 풍부함을 만든다. 자체 모델도 큰 수관, 낮은 관목, 작은 풀의 세 크기로 구성하고 같은 재질 체계를 공유한다. 비슷한 나무를 단순 복제하기보다 줄기 기울기·수관 외곽·군집 간격을 바꾼다.
- 적합성: 자체 숲 모델 구성과 재질 통일의 참고로 높음. 실시간 엔진 셰이더나 판매 화면의 결과가 PNG에 자동으로 따라온다고 가정하지 않는다.

## 독자적인 아트 방향

다음은 위 상품들의 파일을 모방·변환하는 지침이 아니라, Glintgrove의 퍼즐 구조에 맞춰 정한 제작 원칙이다.

| 요소 | 직접 제작할 표현 | 게임에서 지킬 기준 |
| --- | --- | --- |
| 숲의 공간 | 깊은 남색 원경, 중간 거리의 차가운 청록 수관, 가장자리의 짙은 줄기와 잎 | 중앙 퍼즐 영역에는 조용한 바닥과 낮은 대비를 남긴다. 화면 비율이 달라도 나무가 버튼·보드를 가리지 않는다. |
| 표면 | 부드러운 명암과 큰 붓질 같은 색면, 약한 재질 변화 | 축소하면 사라지는 잡음이나 사진 같은 미세 질감을 주된 장식으로 삼지 않는다. |
| 조명 | 차가운 달빛, 작은 금빛 광원, 제한된 발광 식물 | 가장 밝은 것은 퍼즐 광선과 활성 상태다. 장식용 빛이 게임 상태처럼 보이지 않아야 한다. |
| 나무·꽃·버섯·부엉이 | 같은 시점과 기준점, 읽기 쉬운 수면/활성 상태 | 활성 차이를 색상 하나에만 맡기지 않고 실루엣·열림·눈·주변 효과로 보조한다. 요구 색 배지를 유지한다. |
| 거울·분광기 | 자체 황동/목재 받침, 방향이 선명한 반사면 | `/`와 `\` 방향을 작은 칸에서도 구별한다. 고정 그림자와 회전하는 면을 분리한다. |
| 수정·게이트·포털 | 큰 면, 서로 다른 외곽, 절제된 발광 | 색상 요구와 통과/차단 상태를 오브젝트 장식보다 우선한다. |
| UI | 남색·황동·상아색의 얇은 테두리, 독자적인 선 아이콘 | 한국어·영어 글자 폭, 키보드 초점, 눌림·비활성 상태를 실제 HTML에서 확인한다. |

Blender에서는 동일한 정사영 카메라와 조명 설정으로 모델을 렌더한다. 이미지 생성에는 이 문서의 재질·팔레트·공간 요구를 독자적인 문장으로 전달한다. 제작사명이나 특정 상품을 그대로 복제하도록 지시하지 않으며, 생성 이미지의 가격·모델 선택은 실행 단계에서 현재 사용 가능한 경로와 0원 추가 결제 조건을 따로 확인한다.

## 적용과 검수 기준

기존 `src/render/renderer.js`는 Canvas 2D이고 `src/render/entities.js`에 오브젝트별 그리기가 분리되어 있다. 외부 3D 실행 엔진을 추가하기보다 자체 렌더 이미지를 현재 퍼즐 좌표에 그리는 방식을 유지한다. 자세한 미술 방향과 배경은 바꿀 수 있어도 광선 계산과 조작 방향의 의미는 그대로 보존한다.

- 오브젝트 원본은 충분한 해상도로 제작하되 먼저 256px급 타일 출력으로 확인한다. 현재 칸은 14–96 CSS px이고 DPR 상한은 2이므로, 큰 원본의 세부 묘사보다 실제 작은 화면에서의 구분이 중요하다.
- 배경은 레벨·시드·화면 크기에 따라 다시 합성해 캐시하고 매 프레임 재사용한다. 큰 장식이 레벨마다 다른 보드 크기를 침범하지 않도록 한다.
- 이미지 사전 로딩과 실패 시 대체 그리기, 로컬 파일 경로, 서비스 워커 캐시를 함께 확인한다. CSP의 외부 이미지 허용 범위를 넓힐 필요가 없다.
- 초반의 단순한 레벨과 조밀한 후반 레벨, 모바일 세로·데스크톱 가로, 수면·활성 상태, 효과 감소 설정을 함께 비교한다.
- 가장자리의 불투명 사각형·흰 테두리, 회전 시 부자연스러운 그림자, 배지 가림, 전체 화면의 희뿌연 발광이 없어야 한다.

이 문서의 완료 범위는 출처 조사와 제작 방향이다. 실제 에셋 생성 여부와 비용, 최종 산출물 목록, 게임 적용 및 시각 검수 결과는 후속 제작 기록에서 별도로 확인한다.

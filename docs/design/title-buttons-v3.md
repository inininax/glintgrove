# 메인 버튼 v3 · 황동 프레임

2026-09-14. 보석 게임명과 고대 숲의 질감에 맞춰 메인 화면의 버튼만 다듬었다. 배경·게임명 이미지, 본문, 지도·게임·모달의 공통 버튼 디자인은 이 작업의 대상이 아니다.

- 숲으로 들어가기는 깊은 비취색 유리 면, 얇은 황동 테두리와 안쪽 선으로 강조한다. 양쪽의 작은 보석·직선 장식은 직접 작성한 SVG 기하이며 텍스트가 가운데에 놓이도록 대칭으로 배치한다.
- 이어하기·일일 챌린지는 같은 높이와 글꼴의 2열 버튼을 유지한다. 주 버튼보다 낮은 명암의 프레임으로 단계를 구분한다. 세 버튼은 모두 지도 제목과 같은 `var(--serif)`/400을 사용한다.
- 옵션·도움말은 동일한 48×48px 프레임의 아이콘 버튼이다. 옵션은 톱니, 도움말은 물음표를 표시하며 `title`과 `aria-label`을 기존 번역 키로 갱신한다.
- 모든 메인 버튼에 같은 대칭 모서리·안쪽 선·hover·pressed·키보드 focus 표현을 사용한다. 장식은 포인터 입력을 가로채지 않는다. 기존 ID·이벤트 연결·disabled 동작은 유지한다.
- 480px 이하에서는 장식과 간격을 줄이고, 높이 450px 이하에서는 주 버튼을 58px·보조 버튼을 54px로 줄인다. 작은 화면에서도 두 보조 버튼과 두 유틸리티의 짝은 유지한다. 새 반복 애니메이션은 추가하지 않으며 운영체제의 동작 줄이기 설정은 기존 CSS를 따른다.

외부 이미지·폰트·아이콘 라이브러리를 추가하지 않았다. 이 문서는 설계 변경 기록이며 최종 브라우저 검증 결과를 의미하지 않는다.

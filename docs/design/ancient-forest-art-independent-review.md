# 고대 숲·석문 제작 자료 독립 검토

2026-09-14 · 검토자: 게임 기획 에이전트 · 제작자: 부모 통합 에이전트

범위는 새 GPT 숲 v6, Blender 석문 v2, 해당 카탈로그·배포 이미지·출처 기록 코드다. 검토자가 작성한 UI 표식과 장치 안내, 별도 담당자가 검토하는 음악은 포함하지 않는다.

## Blender 원본과 산출물

`ancient-gates-v2.blend`를 로컬 Blender 5.2.1 LTS에서 `--disable-autoexec --background`로 열어 읽기 전용으로 검사했다. `gate.r`, `gate.g`, `gate.b` 세 장면이 있고 각각 Cycles, 384×384, 투명 배경, 33개 객체를 갖는다. 연결된 외부 라이브러리는 없고 이미지 데이터는 파일 경로가 빈 Render Result/Viewer Node 두 개뿐이다. 글꼴 객체도 없다.

`tools/art/build_ancient_gates_v2.py`를 검토했다. 숫자로 배치한 큐브·곡선·저분할 보석, 절차적 노이즈 범프 재질, 지역 조명과 직교 카메라를 생성하며 외부 이미지나 모델을 불러오는 경로가 없다. 기존 편집 원본이 있으면 기본적으로 중단하고 명시적인 재제작 옵션을 요구한다. 별도 `render_library.py`는 현재 열린 원본의 지정 장면을 렌더하므로 GUI에서 수정한 모델을 보존하는 작업 방식과 맞다.

제작 기록의 master·generator·renderer와 세 원본 PNG의 SHA256 및 바이트 수를 독립 계산해 모두 일치함을 확인했다. 세 PNG는 RGBA이고 중앙 픽셀의 알파가 0이다. 새 붉은 석문 이미지를 직접 확인했으며 이전 사다리형 가로 막대 대신 열린 중앙 통로가 보인다. 카탈로그는 세 v2 원본을 가리키고, 배포된 세 PNG는 각 원본과 디코딩한 RGBA 픽셀이 완전히 같다. 배포 파일명의 12자리 해시도 실제 바이트 해시와 일치한다.

확인 시 매니페스트 리비전: `nocturne-8f72a32c7dc7`.

## GPT 숲과 출처 기록

v6 생성 기록의 원본·전체 프롬프트·참조 v4 PNG 해시를 독립 계산해 모두 일치함을 확인했다. 연결되는 v4 기록의 원본·프롬프트·참조 이미지 해시도 일치했다. v6 기록은 입력을 프로젝트의 이전 v4 한 장으로 밝히며, 정확한 모델 버전을 도구가 반환하지 않았다고 명시한다. 프롬프트는 큰 명암 덩어리·고목·어두운 중앙·제한된 발광을 지시하고 외부 게임의 고유 장면이나 작가 이름을 요구하지 않는다.

`tools/record-visual-provenance.mjs`는 v6와 새 석문 기록을 등록한다. 새 스프라이트는 해당 장면의 출력과 원본 `.blend` 해시를 연결한다. GPT 참조는 재귀적으로 검증하고 순환·누락·복수 후보 기록은 검증 성공으로 취급하지 않는다. 별도의 파일 목록에 생성기·프롬프트·기록도 포함한다. 검증 범위가 파일 기록의 일치이며 법적 권리나 정확한 모델의 독립 검증은 아니라고 명시한 점을 확인했다.

검토 범위에서 제작 방식 설명과 로컬 증거 사이의 차단 결함은 발견하지 않았다. 이 결과는 파일과 코드의 기술적 출처 일치 검토이며, 외부 저작물과의 세계적인 유사성 검색이나 법률상 비침해 보증은 아니다. 최종 통합 후 UI 수정분까지 포함하도록 출처 기록과 배포 빌드를 다시 생성해야 한다.

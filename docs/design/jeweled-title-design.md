# 보석 타이틀과 첫 화면의 메뉴

2026-09-14. 이전 고대 숲의 색과 배경을 유지하면서, 사용자가 요청한 메뉴 구조와 보석을 결합한 게임명을 적용한다.

## 구성

별도의 위쪽 심벌은 없애고, 금색 글자와 초록 보석이 한 덩어리로 그려진 ILYNDREL 이미지 하나를 h1으로 사용한다. 실제 원본 크기 2172×724, 표시 비율 3:1, `object-fit: contain`으로 중앙 펜던트까지 모두 보인다. 제목 대체 텍스트는 Ilyndrel이다.

설명은 기존 문장을 유지하고 큰 화면에서 18px, 모바일에서 17px로 키운다. 이미지→설명→메뉴 사이에는 각각 일정한 여백을 둔다. 메뉴 폭은 큰 화면에서 최대 440px이며 좁은 화면에서는 사용 가능한 폭을 채운다.

1. 숲으로 들어가기: 메뉴 폭 전체를 사용하는 금색 버튼.
2. 이어하기 / 일일 챌린지: 바로 아래 동일한 두 열의 윤곽선 버튼.
3. 옵션 톱니바퀴 / 도움말: 마지막의 작은 보조 동작 행.

주요 세 버튼은 모두 숲의 지도 제목과 같은 `var(--serif)`, 굵기 400을 사용한다. 큰 화면 22px, 높이 62px로 맞춘다. 모바일은 세 버튼에 같은 반응형 글자 크기와 60px 높이를 적용한다. 톱니바퀴는 직접 작성한 SVG 도형이며, 보이는 글자가 없어도 '옵션'이라는 접근성 이름과 툴팁을 제공한다.

## 검정 매트 이미지의 합성

최종 생성 이미지에는 실제 alpha가 없으므로 검정 매트 원본을 WebP에 그대로 보존하고, 화면에서 `mix-blend-mode: screen`으로 합성한다. 원본 픽셀에서 검정을 지우거나 별도 alpha 마스크를 만들지 않는다. 생성 원본·프롬프트·출처 기록은 `art/recipes/ilyndrel-wordmark-v2.json`을 기준으로 확인한다.

screen 합성이 숲까지 닿도록 타이틀 화면만 `position: absolute`, `z-index: auto`, `isolation: auto`로 두고, 중앙 베일 다음에 제목 구성을 그린다. 고정 위치 요소는 `z-index: auto`여도 자체 스태킹 컨텍스트를 만들기 때문에 이 부분은 함께 바꾼다. 다른 화면과 모달은 기존 층을 유지한다. 이 결정은 [MDN의 스태킹 컨텍스트 문서](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Positioned_layout/Stacking_context)를 확인한 뒤 적용했다.

## 실제로 작동하는 도움말

타이틀의 도움말은 기존 장치 안내 모달을 열고, 먼저 퍼즐 목표·조작·세 메뉴의 차이를 설명한다. 이어서 모든 장치를 소개한다. 마지막에 플레이한 퍼즐이나 타이틀 배경용 데모에 어떤 장치가 있었는지는 안내 내용에 영향을 주지 않는다.

도움말은 스테이지를 시작하거나 힌트를 요청하지 않고, 이동 횟수·별·진행 데이터·첫 안내 완료 여부를 바꾸지 않는다. 타이틀에서 도움말을 읽은 뒤 처음 이어하기를 눌러도 기존 첫 플레이 안내가 정상적으로 나온다.

열린 도움말에서 Tab은 모달 안에 머무르고 Escape 또는 닫기로 돌아오면 도움말 버튼에 초점을 복원한다. 옵션과 도움말은 서로 겹쳐 열리지 않으며, 모달 뒤의 세 시작 버튼과 게임 단축키는 작동하지 않는다. 게임 중 장치 안내는 기존처럼 해당 퍼즐에 필요한 장치를 보여준다.

## 검증 범위

UI·언어·튜토리얼·장치 안내 테스트 27개가 통과했다. 새 회귀 검사는 실제 main.js 버튼 연결을 통해 도움말 열기, 뒤 메뉴 차단, Escape, 초점 복원, 진행 보존과 첫 플레이 안내 보존을 확인한다. 저장된 게임 상태가 없거나 마지막 퍼즐을 이미 완료한 경우에도 타이틀 도움말을 열 수 있음을 검사한다.

통합 담당자가 Ego에서 캡처한 1440×900, 390×844, 614×427 화면을 확인했다. 검정 사각형 없이 숲 위에 합성되며, 펜던트와 글자가 잘리지 않고 낮은 창에서도 모든 메뉴가 화면에 들어온다. 캡처는 `/tmp/ilyndrel-jeweled-desktop-v2.png`, `/tmp/ilyndrel-jeweled-mobile-v2.png`, `/tmp/ilyndrel-jeweled-short-v2.png`다. 실제 버튼 높이·글꼴 일치, 도움말·설정 상호작용의 최종 독립 검증은 통합 담당자와 별도 검토자가 수행한다. 제작자의 코드 검사로 최종 승인을 대신하지 않는다.

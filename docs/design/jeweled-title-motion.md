# 보석빛 타이틀: 숲의 움직임 보정

2026-09-14 · 배경 모션 구현 기록

## 관찰과 방향

기존 숲은 이미 안개·광선·수면 반사·작은 빛을 Canvas로 움직이고 있었다. 그러나 안개의 투명 스탬프에 낮은 불투명도가 다시 곱해지고 이동 속도도 매우 낮아, 타이틀의 어두운 베일 뒤에서는 정지 배경처럼 느껴질 수 있었다.

원본 `forest-v6` 픽셀과 화면 배치는 유지한다. 타이틀에서만 움직임의 깊이와 가시성을 조정하고 게임판·지도의 대기 효과는 기존 강도로 남긴다. 입자를 늘리는 대신 세 깊이의 안개가 서로 다른 속도로 움직이고, 물 위의 작은 반사가 명암을 바꾸도록 했다.

## 구현

- `src/render/renderer.js`의 배경 분기에서 타이틀 여부를 `drawAtmosphere`에 전달한다. 빔·목표·시뮬레이션 동작은 수정하지 않는다.
- 먼 안개는 낮은 강도와 작은 이동을 유지하고 가까운 안개는 더 넓게 이동한다. 390px 화면 기준 첫 5초에 가까운 안개가 8px 이상 이동하여 몇 초 동안 바라보면 흐름을 알 수 있다.
- 타이틀의 낮은 안개에 완만한 명암 변화를 넣는다. 중앙의 텍스트 위계와 고목의 깊이를 해치지 않도록 화면 하단 쪽에 배치한다.
- 얇은 수면 반사 7개의 변화 속도와 가시성을 높이고, 384×128 투명 Canvas에 미리 그린 물빛 스탬프 하나를 재사용한다. 매 프레임 추가되는 작업은 이 스탬프의 `drawImage` 한 번이다.
- 작은 빛은 기존과 같은 6~12개다. 타이틀에서는 좌우로 나눠 중앙의 글자 영역을 비우고 작은 빛의 크기·이동·밝기만 조정했다.
- 시간에 따른 위치와 밝기는 연속된 사인·코사인 함수다. 화면 밖으로 입자를 재배치하거나 반복 경계에서 좌표를 초기화하지 않는다.
- 설정의 움직임 끄기와 OS의 모션 감소는 기존의 별도 배경 시계를 정지시킨다. 다시 켜면 멈춘 위치에서 이어진다.

## 검증과 인계

`node --test tests/backgroundMotion.test.mjs tests/beamContact.test.mjs`에서 20개 테스트가 통과했다. 새 테스트 3개는 타이틀 안개의 전후 깊이 차이, 같은 입자 수와 조용한 중앙 영역, 게임에서 강화 효과 미사용, 큰 화면 및 긴 실행 시간에서의 연속성, 지도↔타이틀 전환 시 Canvas 재사용을 확인한다. 기존 설정·OS 모션 정지·재개와 게임판 레이어 테스트도 통과했다.

원본 생성·음악·UI 파일·서버는 변경하지 않았다. 실제 브라우저에서 새 타이틀 아트와 함께 보이는 최종 강도 검수는 부모 통합 에이전트에게 인계한다. 이 문서는 구현자의 제작 기록이며 독립 검토를 대체하지 않는다.

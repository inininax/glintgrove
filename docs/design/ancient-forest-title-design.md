# 고대 숲의 입구: 타이틀 화면 디자인

작성일: 2026-09-13. 범위: 첫 화면의 구성, 명암, 읽기 순서. 게임 중 HUD와 장치의 규칙은 별도 기획 범위다.

## 관찰한 문제

이전 데스크톱·모바일 실행 화면과 실제 투명 이미지 파일을 함께 확인했다. 로고와 제목이 떨어져 보인 주원인은 HTML 간격만이 아니라 워드마크 원본 내부의 넓은 투명 여백이다. 원본은 2048×768이며, alpha 32 이상인 실제 글자의 세로 범위는 185–588px이다. 기존 600px 표시 폭에서는 이미지의 투명한 윗부분만 약 54px를 차지했다. 심벌 아래 여백까지 더해지면서 하나의 게임 로고가 두 개의 분리된 덩어리로 보였다.

제목 아래 설명은 수풀과 물의 작은 밝은 무늬 위에 놓여 읽기 어려웠다. 전체 화면을 똑같이 어둡게 하기보다, 제목·설명·버튼 뒤의 중앙 영역을 차분하게 만들 필요가 있다.

## 외부 참고 자료와 해석

외부 게임의 공식 소개와 이미지는 빛의 위계, 공간의 깊이, 화면의 읽기 순서를 분석하는 참고로만 사용했다. 다음 원칙은 이 프로젝트를 위한 디자이너의 해석이며, 해당 제작사가 발표한 디자인 규칙이라는 뜻은 아니다.

| 공식 자료 | 참고한 점 | Ilyndrel에 적용하는 원칙 |
| --- | --- | --- |
| [Team Cherry — Hollow Knight](https://www.hollowknight.com/)의 Lake of Unn 및 공식 헤더 이미지 | 가까운 구조물의 선명한 실루엣, 멀리 갈수록 단순해지는 큰 명암 덩어리, 제한된 빛의 초점 | 나뭇잎 하나하나보다 고목과 뿌리의 큰 형태를 우선하고, 밝은 부분의 개수를 줄인다. |

확인한 타사 이미지는 저장소, 배포 에셋 또는 이미지 생성의 입력으로 추가하지 않았다. 소유 캐릭터, 로고, 고유 건축물, 특정 장면의 구도를 재현하는 지시도 하지 않았다. 새 배경 생성 기록과 실제 입력 파일은 `art/recipes/`의 해당 생성 기록을 기준으로 확인한다.

## 최종 구성 의도

상징 → 게임명 → 기존 설명 → 숲으로 들어가기 → 설정 → 작은 이어하기·일일 챌린지 순으로 읽힌다. 상징과 게임명은 `.title-identity` 한 그룹으로 묶는다. 모서리 문구와 별도 장식 선은 두지 않는다.

- 큰 화면에서 심벌 88px, 게임명 최대 폭 580px, 두 이미지의 레이아웃 간격 8px로 정한다.
- 워드마크는 원본을 변경하지 않고 `object-fit: cover`와 4.2:1 표시 영역으로 투명한 상하 여백을 제외한다. 이 표시 영역은 원본 y≈140–628px에 해당하므로 실제 글자와 아래로 뻗은 장식이 모두 포함된다.
- 설명은 14px, 시작 버튼은 20px로 설정하고 밝은 아이보리와 금색으로 차등을 준다. 설정은 시작 버튼 바로 아래에 44px 이상의 누르기 영역을 유지한다.
- 중앙은 경계가 없는 청록색 타원 그라데이션으로 더 어둡게 만든다. 이는 타이틀 화면에만 적용되며 게임판에 덮이지 않는다. 좌우의 큰 고목과 숲의 색은 남긴다.
- 모바일에서는 암부의 폭을 넓혀 긴 제목의 양 끝과 설명도 밝은 수풀 위에 직접 겹치지 않게 한다.
- 낮은 창에서는 이미지와 간격을 함께 줄인다. 화면보다 내용이 커지는 환경은 세로 스크롤로 접근할 수 있게 하고, 버튼을 화면 바깥으로 잘라 숨기지 않는다.

## 구현 및 확인

수정 파일은 `index.html`의 타이틀 그룹과 `css/style.css`의 타이틀 관련 규칙이다. 이미지 원본과 기존 버튼 ID, 한국어 설명, 접근성 제목은 보존했다. 심벌은 장식 이미지이며 워드마크의 대체 텍스트가 문서의 h1 제목을 제공한다.

기존 UI·언어·튜토리얼 회귀 테스트 19개 통과. alpha 범위를 읽어 글자가 표시 영역 안에 포함되는지 확인했다. 통합 담당자가 Ego에서 캡처한 최종 배경과의 1440×900, 390×844, 614×427 화면을 확인했다. 첫 캡처에서는 이미지의 고유 높이가 표시 영역보다 우선되어 공백이 남는 문제를 발견했고, 이미지를 비율 영역 안에 절대 배치하여 수정했다. 두 번째 캡처에서 실제 공백 감소, 글자 장식 보존, 낮은 화면의 메뉴 접근을 확인했다. 중앙 베일도 새 배경의 어둠을 고려해 최대 불투명도를 70%로 낮췄다.

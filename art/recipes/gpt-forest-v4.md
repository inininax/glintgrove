# GPT 숲 배경 v4

제작일: 2026-09-13. 사용자가 요청한 GPT 이미지 생성으로 숲 배경 한 장을 개선했다. 기존 청록·옥색 그림자와 부드러운 금빛을 유지하면서, 풍성한 수관·고목·고사리·이끼·굽이치는 물길이 먼 안개 속으로 이어지도록 구성했다.

## 제작 입력과 원본

- 도구: 이 대화의 내장 `image_gen.imagegen`. 도구가 정확한 모델 버전을 반환하지 않았으므로 특정 GPT Image 버전으로 표시하지 않는다.
- 참조: 이 작업 폴더에서 Blender로 만든 `art/source/procedural/forest-v3.png` 한 장. 색감과 분위기를 참고했으며 외부 게임 이미지나 작가 스타일 참조를 추가하지 않았다.
- [실제로 전달한 전체 프롬프트](gpt-forest-v4.prompt.txt)와 [입력·출력 해시 기록](gpt-forest-v4.json)을 함께 보존한다.
- 생성 원본: `art/source/gpt/forest-v4.png`, 불투명 RGB PNG, 1536×1024. 도구 출력의 바이트를 그대로 보관한다. 이 파일은 Blender 장면이나 편집 가능한 3D 모델이 아니다.

## 화면 구성과 적용

게임은 배경의 중앙을 기준으로 화면을 가득 채우며, 세로 화면에서는 양옆이 잘린다. 따라서 중앙 약 30%에도 물길·먼 숲의 입구·위쪽 수관이 남도록 요청했다. 잎과 뿌리의 세부 묘사는 가장자리에 두고 제목·퍼즐이 놓이는 중앙은 상대적으로 낮은 대비를 유지한다. 애니메이션은 기존 Canvas 안개·물빛·반딧불 효과가 계속 담당한다.

`art/recipes/catalog.json`의 `forest`만 이 원본을 가리킨다. 다른 세 배경과 Blender 소품 21개는 유지한다. 의미 ID를 유지하므로 제목·지도와 숲 배경을 사용하는 퍼즐에 함께 적용된다. 간결한 도형 표시는 기존 코드 배경을 사용한다.

```bash
.venv-art-build/bin/python tools/art/publish_art.py
npm run check:assets
node tools/record-visual-provenance.mjs
npm run build
```

내보내기는 RGB WebP, 품질 88·method 6이며 해시가 붙은 새 서비스 파일을 만든다. 기존 v3 PNG와 `.blend`, v2 제작 기록, 이전 서비스 이미지는 덮어쓰거나 삭제하지 않는다. 다음 수정은 새 버전의 PNG·정확한 프롬프트·참조/출력 해시를 저장한 뒤 카탈로그와 출처 기록 도구의 증거 목록을 갱신한다. 이미지 생성 결과는 같은 프롬프트로 픽셀 단위 재현을 보장할 수 없으므로 생성 원본 자체를 보관한다.

이 기록은 사용한 도구와 파일의 추적 자료다. 사람만의 수작업 제작, 독점 저작권, 계약상 권리 귀속이나 제3자 권리 비침해를 확인했다는 뜻이 아니다. 예전 이미지 모델 배경의 은퇴 기록과 이번 명시적 GPT 생성 요청은 별도로 관리한다.

# Forest Reverie · original background music

Ilyndrel용으로 작성한 72초짜리 잔잔한 연주곡이다. 음정과 배치를 직접 정한 악보를 Node.js의 수학적 음원 합성기로 렌더했다. 외부 음악, 녹음, 샘플, 가사, 보컬, 음성, 타격음은 사용하지 않았다. GPT 음악 서비스의 결과물이 아니라 프로젝트 안에 포함된 악보와 합성 코드로 만든 음악이다.

이 문서는 v1 제작·적용 당시의 기록이다. 현재 게임은 [96초 Ancient Forest v2](ancient-forest-v2-music.md)를 사용한다. v1 악보·합성기·해시 기록은 아래 제작 경로에 유지하며, 사용하지 않는 WAV는 현 에셋 폴더에서 정리하고 [커밋 e355b1b의 보존본](https://github.com/inininax/glintgrove/blob/e355b1b8ffa46d2047dcbd427fa20ebb37c5c6a0/assets/audio/forest-reverie-v1.wav)으로 남겼다. 아래 경로·재생 길이·업데이트 명령은 v1 당시 기준이며, 현재 로더·테스트·배포 목록의 기준은 v2 레시피를 따른다.

## 파일 구조

```text
art/source/audio/forest-reverie-v1.score.json  # 수정 가능한 음정·시각·음량·팬 악보
tools/audio/render-forest-music.mjs           # 외부 패키지가 필요 없는 합성기
art/recipes/forest-reverie-v1-music.json       # 출처, 파일 해시, 오디오 측정값
assets/audio/forest-reverie-v1.wav            # 당시 배포 경로; 현재는 위 Git 보존본
src/fx/music.js                              # 당시 파일 로더와 길이 검사; 현재 v2 사용
src/fx/sound.js                              # 음악 재생·반복·음소거 및 게임 효과음
```

## 곡과 소리

- 18초마다 천천히 바뀌는 네 개의 부드러운 화음. 낮은 E–C–G–A를 바탕으로 D·G·A·B·E 음을 넓게 배치했다.
- 72초 동안 12개의 부드러운 펠트 계열 음과 4개의 작은 유리 계열 음을 드문드문 배치했다. 악기명은 합성 음색의 설명이며 실제 악기 녹음을 사용하지 않았다.
- 느린 어택과 릴리스, 약한 배음, 작은 좌우 공간감, 감쇠되는 잔향으로 숲의 깊이를 표현한다. 리듬을 재촉하는 드럼이나 강한 선율은 없다.
- PCM WAV, 24,000 Hz, 스테레오, 16비트, 1,728,000프레임, 정확히 72초. 파일 크기는 6,912,044바이트다. 낮게 제한한 고음역에 맞춰 용량을 줄였다.
- 파일 피크는 약 0.30, RMS는 약 0.069다. 재생 시 음악 게인 0.5 × 공통 마스터 0.62를 적용해 게임 효과음 아래에 둔다.

## 무한 반복 구조

음 하나와 잔향이 파일의 끝을 넘어가면 나머지 샘플을 파일의 시작에 합산한다. 마지막 화음과 첫 화음이 자연스럽게 겹치는 상태까지 처음부터 렌더하므로 끝부분을 무음으로 페이드아웃하지 않는다. 순환 저역 필터와 DC 보정도 같은 순환 신호에 적용한다.

브라우저에서는 한 개의 `AudioBufferSourceNode`에 `loop=true`, `loopStart=0`, `loopEnd=72`를 설정한다. 타이머로 파일을 다시 여는 방식이 아니므로 타이머 지연이나 압축 인코더 패딩이 반복 구간에 들어가지 않는다. Web Audio의 [AudioBufferSourceNode 반복 규격](https://www.w3.org/TR/webaudio/#looping)을 사용한다.

첫 실제 클릭·터치·키 입력으로 오디오가 활성화된 뒤 파일을 불러오고 1.6초 동안 서서히 음량을 올린다. 타이틀·지도·스테이지를 이동해도 같은 재생 소스를 유지한다. 음소거나 숨겨진 탭에서는 즉시 소스를 멈추고 현재 위치를 기억한다. 다시 켜면 같은 위치에서 재생하며, 숨겨진 탭에서 돌아온 뒤에는 기존 오디오 정책에 따라 다음 실제 입력으로 컨텍스트를 재개한다. 파일이 없어도 게임 효과음과 게임 플레이는 계속된다.

## 업데이트

1. `art/source/audio/forest-reverie-v1.score.json`에서 음정(MIDI 번호), 시각(초), 음량, 좌우 팬을 수정한다.
2. 저장소 루트에서 `node tools/audio/render-forest-music.mjs`를 실행한다. WAV와 해시·측정 기록을 함께 갱신한다. 같은 소스·코드로 다시 실행하면 같은 바이트가 생성된다.
3. `node --test tests/music.test.mjs tests/sound.test.mjs`로 루프 경계, 음량 여유, 무음, 로딩 실패와 음소거·탭 전환을 검사한다. 실제 재생으로 음색과 반복의 자연스러움도 확인한다.
4. 배포 후 파일 내용을 바꾸는 새 버전은 `v2`처럼 새 파일명을 사용하고 로더, 빌드 포함 목록과 서비스 워커 음악 캐시를 함께 갱신한다. 길이·샘플률을 바꾸면 `src/fx/music.js`의 크기와 길이도 갱신한다.
5. 최종 `npm run build`로 런타임 파일에 포함한다. 악보와 합성기는 배포 디렉터리에 넣지 않는다.

자동 검사는 반복 경계의 샘플 차이가 일반적인 샘플 변화보다 작은지와 무음이 없는지 검증한다. 음질·선호에 대한 청취 평가는 이 수치 검사와 별개다.

# Ancient Forest — A Light Between Roots

Ilyndrel의 고대 숲을 위한 현재 배포용 96초 연주곡이다. 악보의 음정·배치와 Node.js 합성 코드를 새 버전으로 작성했다. 외부 곡, 녹음, 샘플, 가사, 목소리, 합창은 사용하지 않았다. 오디오 생성 서비스에 프롬프트를 보내 얻은 파일이 아니라, 저장소의 악보와 수학적 합성기로 만든 PCM 음원이다. 기존 72초 `Forest Reverie` 악보·생성기는 원래 제작 경로에 유지한다. 미사용 v1 WAV는 현재 `assets/audio/`에서 정리했으며 [기존 커밋의 WAV](https://github.com/inininax/glintgrove/blob/e355b1b8ffa46d2047dcbd427fa20ebb37c5c6a0/assets/audio/forest-reverie-v1.wav)로 보존한다.

## 파일 구조

```text
art/source/audio/ancient-forest-v2.score.json      # 수정 가능한 악보·음색·잔향 설정
tools/audio/render-ancient-forest-music-v2.mjs     # 샘플을 사용하지 않는 결정적 합성기
art/recipes/ancient-forest-v2-music.json           # 원본·생성기·WAV 해시와 측정값
assets/audio/ancient-forest-v2.wav                # 배포용 음악
src/fx/music.js                                  # 활성 곡 경로·길이·크기 검사
src/fx/sound.js                                  # 기존 연속 재생·반복·음소거 처리
```

## 소리의 방향

E의 단조 분위기를 중심으로 C·G·D·A 계열의 열린 확장 화음을 천천히 오간다. 화음은 16초마다 시작하고 각각 32초 동안 이어져, 이전 화음의 뒤쪽이 다음 화음 안으로 스며든다. 마지막과 첫 화음은 E 계열을 공유한다.

패드는 7초에 걸쳐 부드럽게 커지고 14초에 걸쳐 사라진다. 저음의 비중을 낮추고 38Hz 아래를 완만하게 덜어, 효과음과 생각을 방해하는 낮은 울림을 줄였다. 약한 배음과 아주 작은 음정 흔들림은 순수 발진기로 합성하며 사람 목소리의 포먼트나 합창을 모델링하지 않는다.

96초에 펠트 계열 음 3개와 유리 계열 음 7개만 드문 간격으로 둔다. 두 음색 모두 실제 악기 녹음이 아니다. 펠트 음은 0.32초, 유리 음은 1.2초에 걸쳐 올라와 뚜렷한 타격을 피한다. 규칙적인 드럼이나 앞에 나서는 반복 선율은 없다.

최대 8초의 좌우 교차 잔향을 적용하고 잔향의 고음을 부드럽게 감쇠한다. 화음이 겹칠 때의 음량 편차는 3.2초 길이의 순환 에너지 창으로 완만하게 보정한다. 신호의 피크를 깎는 강한 리미터나 끝을 무음으로 만드는 페이드는 사용하지 않는다.

## 반복과 측정

WAV는 24,000Hz·스테레오·16비트 PCM, 2,304,000프레임, 정확히 96초이며 9,216,044바이트다. 압축 인코더의 앞뒤 패딩이 없다. 음과 잔향이 96초를 넘으면 나머지 샘플을 시작 지점에 합산하며, 필터 상태와 음량 보정도 같은 순환 구간에서 계산한다.

재생에는 기존 `AudioBufferSourceNode` 한 개와 `loop=true`를 사용한다. `loopEnd`는 디코딩된 음원의 96초 길이를 따른다. 타이틀·지도·게임을 오갈 때 새 파일을 다시 시작하지 않으며, 음소거·탭 숨김 이후에는 기존 처리로 기억한 위치에서 이어진다. 첫 실제 사용자 입력 후 로드하고 1.6초 동안 서서히 재생 음량을 올린다.

최종 렌더의 피크는 약 0.280, 전체 RMS는 약 0.076이다. 1초 단위 RMS는 약 0.055–0.095 범위이며 무음 구간이 없다. 좌우 상관계수는 약 0.934다. 재생 음량은 기존 음악 게인 0.5 × 마스터 0.62를 적용한다. 정확한 측정값과 해시는 JSON 기록이 기준이다.

경계 검사는 마지막→첫 샘플의 변화량만 전곡 평균과 비교하지 않는다. 정상적인 파형도 영점을 통과할 때 변화량이 클 수 있으므로, 반복 경계 양쪽의 인접 기울기와 곡률이 자연스럽게 이어지는지 함께 확인한다. 추가로 무음, 큰 음량 편차, DC 오프셋, 스테레오 상태와 완전한 PCM 길이를 검사한다.

## 수정과 재생성

1. 악보 JSON의 MIDI 음정, 시각, 음량, 팬, 어택·릴리스, 잔향을 수정한다.
2. `node tools/audio/render-ancient-forest-music-v2.mjs`로 WAV와 해시 기록을 함께 생성한다.
3. `node tools/audio/render-ancient-forest-music-v2.mjs --check`로 같은 Node.js 환경에서 WAV와 생성 기록이 바이트 단위로 재현되는지 확인한다. 이 모드는 파일을 쓰지 않는다.
4. `node --test tests/music.test.mjs tests/sound.test.mjs`로 반복·로딩·음소거·위치 복원과 재현 검사를 실행한다. 실제 재생에서 음색과 장시간 반복의 피로감도 별도로 확인한다.
5. 배포 후 변경은 새 버전 파일명으로 만든다. 로더의 경로·길이·최대 크기, 서비스 워커의 지연 캐시 경로, 빌드의 포함 목록, 시각·음악 출처 기록을 함께 갱신한다. 악보와 생성기는 배포 폴더에 넣지 않는다.

이 기록은 생성 방식과 파일의 대응 관계를 설명한다. 자동 수치 검사는 청취 평가를 대신하지 않으며, 제작자는 이번 작업에서 실제 스피커로 들었다고 주장하지 않는다. 최종 청취·통합 검토는 별도 검증 단계로 남긴다.
